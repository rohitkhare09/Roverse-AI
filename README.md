# 🚀 Roverse AI

Modern AI-powered chat application built with Next.js, Gemini AI, Assistant UI, and Vercel.

🌐 Live Demo: https://roverse-ai.vercel.app/

## Features
- Real-time AI chat
- Gemini 2.5 Flash
- Streaming responses
- Dark mode UI
- Multiple chat threads
- Responsive design

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Assistant UI
- Vercel AI SDK
- Google Gemini API

## Getting Started

npm install

Create `.env.local`

GOOGLE_GENERATIVE_AI_API_KEY=YOUR_API_KEY

npm run dev

## Deployment

Hosted on Vercel
